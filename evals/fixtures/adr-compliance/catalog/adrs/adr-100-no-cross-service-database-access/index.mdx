## Context

Shared databases couple teams to each other's schemas, so a migration in one service can break another.

## Decision

A service must only connect to databases it owns. Data owned by another service must be read through that service's API or built from its events.

## Consequences

Teams can change their schemas independently. Some reads need a local read model.
