## Context

Media jobs need per-message retries and visibility timeouts, which suit a work queue better than a Kafka topic.

## Decision

The Product API sends media jobs to the Product Worker over the `product-media-jobs` SQS queue. This is an agreed exception to ADR-102 for media jobs only. Media jobs are work instructions, not product change events, so they are not written to the outbox.

## Consequences

The Catalog team operates one SQS queue. All other messages stay on Kafka.
